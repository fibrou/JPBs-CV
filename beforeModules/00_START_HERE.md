## 🔧 Technical Requirements

### To Render HTML
- Quarto installed
- R with required packages (tibble, dplyr, etc.)

### To Render PDF
- XeLaTeX installed
- OR use pdflatex (simpler)

### Installation Quick Commands
```bash
# Install Quarto
https://quarto.org/docs/get-started/

# Install R packages
R -e "install.packages(c('tibble', 'dplyr', 'readxl', 'here', 'knitr'))"

# Install LaTeX (Mac)
brew install mactex-no-gui

# Install LaTeX (Ubuntu)
sudo apt-get install texlive-xetex
```
